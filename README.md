# Ravi & Anita — Wedding Invitation

Welcome to the source code for Ravi & Anita's digital wedding invitation! 
This is a beautiful, responsive single-page wedding invitation website built with React and Vite.

## 💍 Live Website
*https://ravi-anita-wedding.onrender.com*

## 🛠️ Tech Stack
- React
- Vite
- CSS3
- Lucide React (Icons)

## 🚀 Run locally
To run this project on your own computer:

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone this repository.
3. Open your terminal in the project folder and run:
```bash
npm install
npm run dev
```
4. Open the local URL provided in your terminal (usually `http://localhost:5173`).

## 📦 Build for Production
To generate the optimized static files for deployment:
```bash
npm run build
```
This will create a `dist` folder containing your minified, production-ready website.

## 📸 Photos
The photos used for the beautiful gallery and profiles are stored inside `src/assets`.
